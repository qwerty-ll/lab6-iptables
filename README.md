# Лабораторная работа 6: Firewall в Linux (iptables NAT router)

Автоматизированный скрипт для настройки маршрутизатора (VM1) и клиента (VM2).
Все параметры (номер варианта $N$, роли машин, сетевые интерфейсы) определяются **полностью динамически**.

---

## 🚀 Быстрый запуск (в одну команду)

### 1. На VM1 (Маршрутизатор):
Выполните в терминале VM1:
```bash
curl -sSL https://raw.githubusercontent.com/qwerty-ll/lab6-iptables/main/run.sh | sudo bash
```
*(Или через wget: `wget -qO- https://raw.githubusercontent.com/qwerty-ll/lab6-iptables/main/run.sh | sudo bash`)*

Что делает VM1:
- Определяет внешний интерфейс (NAT `10.0.2.15`) и внутренний интерфейс (`intnet`).
- Назначает адреса `192.168.109.1/24` (ЛР6) и `192.168.19.1/24` (алиас ЛР5).
- Настраивает постоянную конфигурацию в Netplan и `isc-dhcp-server`.
- Включает IP-форвардинг (`net.ipv4.ip_forward=1`).
- Применяет правила `iptables` (маскарадинг NAT).
- Сохраняет правила в `/etc/iptables-conf/iptables.ipv4`.
- Создает и активирует systemd-сервис `iptables-firewall.service`.
- Запускает локальный HTTP-сервер для раздачи скрипта на VM2 без внешнего интернета.

---

### 2. На VM2 (Клиент):
После завершения настройки VM1 выполните в терминале VM2:
```bash
curl -sSL 192.168.109.1/run.sh | sudo bash
```
*(Или через GitHub: `curl -sSL https://raw.githubusercontent.com/qwerty-ll/lab6-iptables/main/run.sh | sudo bash`)*

Что делает VM2:
- Настраивает внутренний интерфейс `enp0s3`: `192.168.109.10/24` (и резервный `.50`).
- Устанавливает шлюзом по умолчанию VM1: `192.168.109.1`.
- Настраивает DNS-серверы `8.8.8.8`, `1.1.1.1`.
- Проверяет связность:
  1. `ping` до шлюза VM1 (`192.168.109.1`).
  2. `ping` в интернет (`8.8.8.8` через NAT).
  3. `ping` до доменного имени (`ya.ru`).
  4. Трассировку маршрута (`traceroute`).

## 📁 Структура репозитория
- `run.sh` — единый динамический скрипт автонастройки.

- `vm1_router.sh` — обертка для запуска VM1.
- `vm2_client.sh` — обертка для запуска VM2.
